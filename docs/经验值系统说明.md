# 植物经验值系统

基于 PVZClass 实现的植物经验值机制。所有改动集中在 `pvzclass/pvzdll/pch.cpp`。

---

## 一、机制说明

### 1. 经验获取
- 每株植物种植时经验为 **0**（`onPlantCreate` → `InitPlantExperience`）。
- 僵尸被击杀时，其经验值 = **本体 + 一类防具(头盔) + 二类防具(盾牌)** 的**最大生命值**之和：

  ```
  经验 = BodyMaxHealth + HelmMaxHealth + ShieldMaxHealth
  ```

  对应 PVZClass 字段（见 `PVZ.h` 中 `Zombie` 类）：
  | 部位 | 字段 | 偏移 |
  |---|---|---|
  | 本体 | `BodyMaxHealth` | 0xCC |
  | 一类防具(路障/铁桶/矿工帽等) | `HelmMaxHealth` | 0xD4 |
  | 二类防具(铁门/铁梯等) | `ShieldMaxHealth` | 0xE0 |

  > ⚠️ 旧实现多算了 `FlyingMaxHealth`（气球血量），已按需求去掉。气球僵尸的气球不计入经验。

- 击杀植物判定：子弹击中僵尸时（`onProjectileHitZombie`），把发射植物地址写入 `zombie+0x148`；僵尸死亡时（`onZombieRemove`）读取该字段得到击杀植物，再把经验发给它。

### 2. 经验上限
- 默认上限 **45000**，可通过 `PlantVsZombies_EN/seed_experience_limit.ini` 按种子类型单独配置：

  ```ini
  DEFAULT_LIMIT = 45000   ; 默认上限
  0 = 45000               ; Peashooter
  1 = 60000               ; Sunflower 单独设为 60000
  ```

### 3. 满经验均分（核心逻辑）
当某植物获得经验时：
1. 当前植物**先吸收到自己的上限**；
2. 若有**溢出**，剩余经验**瀑布式均分**给**同行(row)**的其他**未满经验**植物；
3. 每轮按 `溢出 / 候选数` 平均分配，被分满的植物下一轮退出候选，剩余继续均分，直到经验分完或再无候选；
4. 若当前植物本就满经验，则全部经验直接进入均分流程。

> "均分"在 `DistributeRowExperience` 中实现，保证经验不被无谓浪费，且只分给同行未满植物。

### 4. 植物死亡经验转移（死亡均分）
当某植物死亡时，其当前经验**全部转移**给**同行(row)**的其他**未满经验**植物。

**实现方式**（延迟分配——避免崩溃）：
1. `onPlantRemove`（PlantDieEvent hook 中）：只读经验+行号 → 存入延迟队列 → 删除记录；
2. `onGameObjectsUpdate`（每帧稳定点，`UpdateGameObjectsEvent` hook `0x4130D0`）：处理队列 → 调用 `DistributeRowExperience` 均分。

> **为什么不直接在 `onPlantRemove` 中调用均分？**
> PlantDieEvent（hook `0x4679B9`）在植物移除中途触发，此时游戏内部植物数组可能不一致。直接在 hook 中遍历植物数组访问到无效指针导致崩溃（已复现：铲除植物瞬间崩溃于 `0x57F51E83`）。延迟到 `onGameObjectsUpdate` 执行时，游戏状态已完全稳定。

**覆盖的死亡类型**（`PlantDieEvent` 在 hook 地址 `0x4679B9` 统一触发，涵盖所有植物消失场景）：
- 铲子铲掉
- 被僵尸啃食至死
- 被碾压（车辆/巨人等）
- 被蹦极僵尸偷走
- 被小丑僵尸炸死
- 被豌豆僵尸射死
- 一次性植物（樱桃炸弹、土豆地雷等）生效后消失
- 其他任何导致植物从场上移除的情况

> 若死亡植物经验为 0 或同行无未满植物，则无经验转移发生。

## 二、代码改动（共 6 处）

### pvzclass/pvzdll/pch.cpp

### 改动 1：新增 `DistributeRowExperience`（均分函数）
位于 `AddPlantExperience` 之前。遍历同行未满植物，瀑布式均分溢出经验。

### 改动 2：重写 `AddPlantExperience`
旧逻辑：超过上限直接截断丢弃。
新逻辑：当前植物吸满 → 溢出部分调用 `DistributeRowExperience` 均分给同行未满植物。

### 改动 3：修正 `onZombieRemove` 经验公式
去掉 `FlyingMaxHealth`，严格按"本体 + 一类防具 + 二类防具"。

### 改动 4：重写 `onPlantRemove` + 新增延迟队列
旧逻辑：直接删除死亡植物的经验记录。
新逻辑：读取死亡植物经验+行号 → 删除记录 → 推入 `g_pendingDeathDists` 延迟队列。
- 新增 `#include <vector>` 和全局变量 `g_pendingDeathDists`。
- 直接从 `plantAddress + 0x1C` 读行号，不构造 `PVZ::Plant` 对象（避免访问部分释放的内存）。

### 改动 5：重写 `onGameObjectsUpdate`
旧逻辑：空函数。
新逻辑：遍历 `g_pendingDeathDists`，逐条调用 `DistributeRowExperience`，最后清空队列。

### 改动 6：`onNewGame` 清理延迟队列
追加 `g_pendingDeathDists.clear()`。

### pvzclass/pvzmain/pvzmain.cpp

### 改动 7：注册 `UpdateGameObjectsEvent`
新增 `UpdateGameObjectsEvent updateGameObjectsEvent;` 的创建和 `end()` 调用。**此事件之前未注册**，导致 `onGameObjectsUpdate` 从不执行。

## 三、编译与部署

### 编译（需要 Visual Studio + C++ 桌面开发工作负载）
> ⚠️ 本机 VS2022 未安装 C++ 工具链，无法在此编译。请在装有 VS C++ 的环境执行。

1. 用 Visual Studio 打开 `pvzclass/pvzclass/pvzclass.sln`。
2. 配置管理器选择 **`Release | Win32`**（PVZ 原版是 32 位，必须用 Win32/x86，不能用 x64）。
3. 在解决方案资源管理器中右键 **`pvzdll`** 项目 → 生成。
4. 生成产物：`pvzclass/pvzdll/Release/pvzdll.dll`（或对应输出目录）。

### 部署
把生成的 `pvzdll.dll` 复制到游戏目录覆盖旧版：
```
PlantVsZombies_EN/pvzdll.dll
```

### 运行
启动 `PlantVsZombies_EN/PlantsVsZombies.exe`，PVZClass 会自动加载 DLL。种植植物后：
- 植物下方显示绿色经验条（满经验时金色边框）；
- 植物**右下角**实时显示经验值数字（黑底白字，满经验时金色）。

数字位置在 `onDrawUITop` 中由 `boxX = plantX + 18`、`boxY = plantY + 12` 控制，可按需调整。

## 四、已知局限与后续可改进

### 击杀来源追踪仅覆盖子弹类攻击
当前通过 `onProjectileHitZombie` 写入 `zombie+0x148`，只能追踪**子弹类**攻击植物（豌豆、雪豌豆、双发、卷心菜投手、玉米投手、西瓜投手、仙人掌、星星果等）。

以下**非子弹**攻击路径不会触发该钩子，击杀僵尸时可能拿不到经验：
- 樱桃炸弹 / 土豆地雷 / 辣椒（爆炸）
- 倭瓜（碾压）
- 食人花（吞噬）
- 地刺 / 钢地刺（踩踏）
- 玉米加农炮（爆炸）
- 大喷菇 / 胆小菇（喷雾——部分可能算 projectile，需测试）

> **待验证**：早期脚本 `final_impl_v2.py` 的注释提到 `zombie+0x148` 是"游戏自身维护、各种伤害路径都会写入"的字段。若属实，则去掉 `onProjectileHitZombie` 的手动写入、纯依赖游戏原生 0x148 即可覆盖所有伤害类型。建议先测试当前版本，确认非子弹植物是否拿到经验，再决定是否调整。

### 改进方向
- 若需覆盖所有伤害来源，可研究 `onZombieHit` 事件或直接依赖游戏原生 `zombie+0x148`。
- 经验条目前画在植物下方，可调整 `onDrawUITop` 中的 `barY` 偏移。
- 可扩展：满经验植物给予增益（如攻速提升、伤害加成）——在 `onPlantReload` / `onPlantShoot` 中根据经验状态调整。
